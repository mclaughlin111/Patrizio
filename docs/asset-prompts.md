# Asset generation prompts

The hero model is a supplied violin USDZ file
(`public/models/violin.usdz`), rendered client-side with `three-usdz-loader`
(see `components/ViolinScene.tsx`). No image/model generation tool was
required for it. These prompts are kept for reference if another generated
supporting asset is wanted later — for use with an image or 3D generation
tool such as Higgsfield AI, Midjourney, or similar.

Do not add API keys to this project to run these. Generate assets externally
and drop the resulting files into `public/assets/generated/`.

## Barber pole (supporting/alternate asset)

> A photorealistic studio product shot of a classic barbershop pole, red and
> white diagonal spiral stripes on a cream cylinder, polished brass cap and
> base, dark walnut base plate, warm daylight from the left, soft shadow
> beneath, clean cream background, generous negative space, editorial product
> photography style, no text or logos visible.

## Shop signage texture (art direction reference only)

> Close-up editorial photograph of a hand-painted cream barbershop signboard
> in a charcoal frame, elegant art-deco serif lettering, muted red and brass
> accents, warm directional daylight, subtle paint texture, no readable
> business name or invented details, shallow depth of field.
